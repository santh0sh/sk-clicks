# SK Clicks

A static, photo-led portfolio. Home, Work, About, Contact.

## Change a photograph

Open `assets/` in this repository. Choose the named image (for example, `hero-sky.jpg` or `work-lotus.jpg`), click **Add file > Upload files**, and upload the new photo with the **same filename**, replacing the old file. Commit the change. GitHub Pages will update the site after deployment. Keep the extension `.jpg` and use a web-sized JPEG.

All site photos live in `assets/`. The public repository contains only the site's HTML and public photographs.
